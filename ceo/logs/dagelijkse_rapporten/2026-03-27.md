**Gmail + Notion MCP moeten eenmalig worden geconfigureerd.**

De permissies staan al goed in settings.json, maar de server-verbindingen ontbreken.
Dit is wat er ingesteld moet worden:

### Stap 1: Notion MCP toevoegen
Open een terminal en typ:
```
claude mcp add --transport http notion https://mcp.notion.com/mcp
```

### Stap 2: Gmail MCP toevoegen
Gebruik de Google Workspace MCP (officieel van Google):
```
claude mcp add --transport http gmail https://gmail.googleapis.com/mcp
```
Of via de marketplace: open Claude Code → Settings → MCP Servers → Add → zoek "Gmail"

### Stap 3: Herstart Claude Code
Na het toevoegen van de servers: sluit Claude Code en open opnieuw.
Type dan weer "start dag" — dan werkt alles.
